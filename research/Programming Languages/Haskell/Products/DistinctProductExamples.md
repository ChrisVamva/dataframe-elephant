# Haskell - Distinct Product Examples

## Financial Systems
- **Standard Chartered Bank** — Trading systems and risk analysis
- **Barclays** — Derivatives trading and pricing engines
- **Jane Street** — Quantitative trading firm (heavy OCaml, but Haskell used in parts)
- **Sigma** — Financial modeling and analysis
- **Lumi (formerly Lumi Financial)** — Financial data processing

## Blockchain & Cryptocurrency
- **Cardano** — Blockchain platform with smart contracts (Plutus)
- **Plutus** — Smart contract language for Cardano (Haskell-based)
- **Marlowe** — Domain-specific language for financial contracts on Cardano
- **Mithril** — Blockchain certification framework

## Compilers & Language Tools
- **GHC (Glasgow Haskell Compiler)** — The reference Haskell compiler
- **HLS (Haskell Language Server)** — IDE support for Haskell
- **Pandoc** — Universal document converter (markdown, LaTeX, HTML, etc.)
- **ShellCheck** — Static analysis tool for shell scripts
- **Hadolint** — Dockerfile linter
- **Stan** — Static analysis tool for Haskell
- **Hoogle** — Haskell API search engine
- **Hackage** — Haskell package repository

## Web Applications
- **Yesod** — Type-safe web framework
- **Servant** — API-first web framework with type-level routing
- **Happstack** — Web application framework
- **IHP** — Integrated Haskell Platform (modern full-stack framework)
- **Fay** — Haskell-to-JavaScript compiler for web frontends

## Data Processing & Analytics
- **Haxl** — Facebook's data access library for Haskell
- **Awake Security** — Network security and threat detection
- **Fugue** — Cloud infrastructure management
- **Haskell for data pipelines** — ETL and stream processing

## Verification & Formal Methods
- **Cryptol** — Domain-specific language for cryptography (Galois)
- **SAW (Software Analysis Workbench)** — Formal verification tool
- **Imperas** — Processor verification
- **Haskell-based theorem provers** — Research and education

## Developer Tools
- **Stack** — Haskell build tool
- **Cabal** — Haskell package and build system
- **HLint** — Haskell code linter and suggester
- **Ormolu/Fourmolu** — Haskell code formatters
- **Weeder** — Dead code detection
- **Hspec** — Testing framework
- **QuickCheck** — Property-based testing library

## Media & Publishing
- **Pandoc** — Used by O'Reilly, Leanpub, and many publishers
- **Gitit** — Wiki system using Git and Markdown
- **Hakyll** — Static site generator

## Scientific Computing
- **Accelerate** — GPU computing library
- **Haskell for research** — Academic and scientific prototypes
- **Bayesian inference** — Probabilistic programming

## Enterprise
- **Facebook (parts)** — Anti-spam systems, data analysis
- **Microsoft (parts)** — Research projects and tools
- **Google (parts)** — Research and internal tools
- **Hasura** — GraphQL engine (written in Haskell)
