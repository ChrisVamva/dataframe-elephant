# PHP - Distinct Product Examples

## Content Management Systems
- **WordPress** — Powers ~43% of all websites on the internet
- **Drupal** — Enterprise CMS for complex, large-scale sites
- **Joomla** — Open-source CMS for publishing web content
- **Magento (Adobe Commerce)** — E-commerce platform
- **PrestaShop** — Open-source e-commerce solution
- **October CMS** — Modern PHP CMS built on Laravel
- **Craft CMS** — Flexible CMS for custom content
- **Statamic** — Flat-file CMS built on Laravel

## E-Commerce
- **WooCommerce** — WordPress e-commerce plugin (largest e-commerce platform)
- **Magento** — Enterprise e-commerce (Adobe Commerce)
- **Shopify (legacy)** — Originally built with PHP (now Ruby)
- **PrestaShop** — Open-source e-commerce
- **OpenCart** — Open-source online store
- **Bagisto** — Laravel-based e-commerce
- **Sylius** — API-driven e-commerce platform

## Web Applications
- **Facebook (legacy)** — Originally built with PHP (now Hack/HHVM)
- **Wikipedia** — The world's largest encyclopedia (MediaWiki)
- **Slack (parts)** — Web application components
- **Etsy** — Marketplace for handmade goods
- **Mailchimp** — Email marketing platform
- **Tumblr** — Microblogging platform
- **Drupal Commerce** — E-commerce framework
- **Laravel applications** — Modern PHP web apps
- **Symfony applications** — Enterprise web applications

## Frameworks & Platforms
- **Laravel** — Most popular PHP web framework
- **Symfony** — Enterprise PHP framework
- **CodeIgniter** — Lightweight PHP framework
- **CakePHP** — Rapid development framework
- **Zend Framework / Laminas** — Enterprise framework
- **Yii** — High-performance PHP framework
- **Phalcon** — C-extension PHP framework
- **Slim** — Micro-framework for APIs
- **Laminas (formerly Zend)** — Enterprise framework

## Developer Tools
- **Composer** — PHP dependency manager
- **PHPUnit** — Testing framework
- **PHPStan** — Static analysis tool
- **Psalm** — Static analysis tool
- **Laravel Forge** — Server management
- **Pest** — Elegant testing framework
- **Infection** — Mutation testing
- **PHP-CS-Fixer** — Code style fixer
- **Rector** — Automated code upgrades

## API & Backend
- **REST APIs** — Laravel, Symfony, Slim, Laminas API Tools
- **GraphQL APIs** — Lighthouse, GraphQL PHP
- **Microservices** — Laravel Lumen, Swoole, RoadRunner
- **Queue systems** — Laravel Queue, RabbitMQ integration
- **Real-time apps** — Ratchet, Swoole, ReactPHP

## Enterprise
- **SAP (parts)** — Enterprise resource planning
- **Salesforce (parts)** — CRM platform
- **Oracle (parts)** — Database and enterprise software
- **IBM (parts)** — Enterprise solutions
- **Drupal government sites** — WhiteHouse.gov (legacy), many government sites

## Media & Publishing
- **WordPress.com** — Blogging platform
- **Medium (legacy)** — Publishing platform (originally PHP)
- **BuddyPress** — Social networking plugin for WordPress
- **bbPress** — Forum software for WordPress
- **MediaWiki** — Wiki software (Wikipedia)

## Community & Social
- **phpBB** — Forum software
- **MyBB** — Forum software
- **Vanilla Forums** — Open-source forum
- **Moodle** — Learning management system
