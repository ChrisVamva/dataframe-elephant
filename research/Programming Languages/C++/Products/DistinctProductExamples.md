# C++ - Distinct Product Examples

## Game Engines & Games
- **Unreal Engine** — Epic Games' AAA game engine (Fortnite, Gears of War)
- **Unity (core)** — Game engine core (C++ with C# scripting layer)
- **CryEngine** — Crytek's game engine (Crysis series)
- **Godot (core)** — Open-source game engine
- **Counter-Strike 2, Dota 2** — Valve games on Source 2 engine

## Operating Systems
- **Windows NT** — Microsoft's operating system family
- **macOS (parts)** — Apple's operating system (XNU kernel, drivers)
- **Linux kernel modules** — Device drivers and kernel extensions
- **ChromeOS** — Google's Chromebook operating system

## Browsers
- **Google Chrome/Chromium** — The world's most popular browser
- **Mozilla Firefox** — Open-source browser
- **Safari (WebKit)** — Apple's browser engine
- **Microsoft Edge** — Chromium-based browser

## Databases
- **MySQL** — Popular open-source relational database
- **MongoDB** — Leading NoSQL document database
- **Redis (parts)** — In-memory data structure store
- **PostgreSQL (parts)** — Advanced open-source database
- **SQLite (parts)** — Embedded database engine
- **ClickHouse** — Column-oriented OLAP database
- **RocksDB** — Embedded key-value store (Facebook)

## Programming Languages & Runtimes
- **LLVM/Clang** — Compiler infrastructure
- **V8 (Chrome JavaScript engine)** — Google's JS engine
- **SpiderMonkey (Firefox JS engine)** — Mozilla's JS engine
- **Java HotSpot JVM** — Oracle's Java virtual machine
- **CPython (parts)** — Python interpreter components

## Graphics & Design
- **Adobe Photoshop/Illustrator** — Industry-standard design software
- **Autodesk Maya/3ds Max** — 3D modeling and animation
- **Blender** — Open-source 3D creation suite
- **AutoCAD** — CAD software for architecture and engineering

## Financial Systems
- **Bloomberg Terminal** — Financial data and trading platform
- **High-frequency trading systems** — Low-latency trading engines
- **Risk management systems** — Real-time risk analysis

## Automotive & Aerospace
- **Tesla Autopilot** — Self-driving software
- **NASA flight software** — Spacecraft control systems
- **Airbus/Boeing avionics** — Flight management systems
- **AUTOSAR** — Automotive software architecture

## Scientific Computing
- **MATLAB (core)** — Numerical computing environment
- **TensorFlow (core)** — Google's ML framework backend
- **PyTorch (core)** — Meta's ML framework backend
- **OpenCV** — Computer vision library
- **ROOT** — CERN's data analysis framework

## Infrastructure
- **Docker (parts)** — Container runtime
- **Kubernetes (parts)** — Container orchestration
- **Envoy** — Service mesh proxy
- **gRPC** — High-performance RPC framework
- **Apache Kafka (client)** — Event streaming client libraries
