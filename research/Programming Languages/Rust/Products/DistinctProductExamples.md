# Rust - Distinct Product Examples

## Systems Programming
- **Linux kernel modules** — Rust is now accepted in the Linux kernel (since 6.1)
- **Windows (parts)** — Microsoft is rewriting Windows components in Rust
- **Android (parts)** — Google is using Rust for low-level Android components
- **Redox OS** — Unix-like operating system written entirely in Rust
- **Tock OS** — Embedded operating system for microcontrollers
- **Fuchsia OS** — Google's capability-based operating system

## Web Browsers & Engines
- **Firefox (parts)** — Mozilla rewriting components in Rust (Stylo CSS engine, WebRender)
- **Servo** — Experimental browser engine (Mozilla, now Linux Foundation)
- **Deno** — Secure runtime for JavaScript and TypeScript (replaces Node.js)
- **SWC** — Speedy Web Compiler (JavaScript/TypeScript compiler)
- **Rspack** — Rust-based JavaScript bundler (Webpack alternative)

## Infrastructure & DevOps
- **Docker (parts)** — Container runtime components
- **Kubernetes (parts)** — Rust-based operators and tools
- **Terraform (parts)** — HashiCorp's infrastructure tools
- **Linkerd** — Service mesh proxy (Rust-based data plane)
- **Vector** — High-performance observability data pipeline
- **Rustls** — Modern TLS library
- **Firecracker** — AWS's microVM technology (Lambda, Fargate)
- **Cloudflare (parts)** — Edge computing and networking

## Databases & Storage
- **TiKV** — Distributed key-value store (TiDB's storage layer)
- **Databend** — Modern cloud data warehouse
- **Greptimedb** — Time-series database
- **SurrealDB** — Multi-model database
- **Meilisearch** — Lightning-fast search engine
- **Qdrant** — Vector database for AI/ML
- **RisingWave** — Streaming database
- **Parquet/Arrow** — Columnar storage and data formats

## CLI Tools
- **ripgrep (rg)** — Extremely fast search tool (grep alternative)
- **fd** — Fast and user-friendly find alternative
- **bat** — Syntax-highlighting cat clone
- **exa/eza** — Modern ls replacement
- **starship** — Cross-shell prompt
- **zoxide** — Smarter cd command
- **bottom (btm)** — System monitor (top alternative)
- **hyperfine** — Command-line benchmarking
- **tokei** — Code statistics (lines of code)
- **cargo** — Rust's package manager and build tool
- **rustup** — Rust toolchain installer
- **clap** — Command-line argument parser
- **nushell** — Modern shell with structured data

## WebAssembly
- **Wasmtime** — WebAssembly runtime
- **WasmEdge** — Lightweight WebAssembly runtime for edge computing
- **Yew** — Frontend web framework (React-like)
- **Leptos** — Full-stack web framework
- **Percy** — Server-rendered WASM web apps
- **Fermyon Spin** — Serverless WebAssembly framework

## Blockchain & Crypto
- **Solana** — High-performance blockchain
- **Polkadot (parts)** — Interoperability blockchain
- **Near Protocol** — Sharded blockchain
- **Parity Ethereum** — Ethereum client
- **Rust Bitcoin** — Bitcoin library
- **Diem (Libra)** — Meta's blockchain project (discontinued)
- **Iron Fish** — Privacy-focused blockchain

## Security Tools
- **RustScan** — Fast port scanner
- **Feroxbuster** — Fast content discovery
- **Httprobe** — HTTP probing tool
- **Sniffglue** — Secure multithreaded packet sniffer
- **AFL++ (parts)** — Fuzzing with Rust components

## Games & Graphics
- **Bevy** — Data-driven game engine
- **Fyrox** — 3D game engine
- **Amethyst (parts)** — Data-driven game engine
- **wgpu** — Cross-platform graphics API
- **Rust-GPU** — Rust shaders for graphics

## Developer Tools
- **rust-analyzer** — Rust language server
- **Clippy** — Rust linter
- **rustfmt** — Code formatter
- **cargo-audit** — Security audit for dependencies
- **cargo-nextest** — Next-generation test runner
- **Miri** — Undefined behavior checker
- **Criterion** — Statistical benchmarking
- **Tarpaulin** — Code coverage tool
