# SQL - Distinct Product Examples

## Relational Database Management Systems
- **PostgreSQL** — Advanced open-source RDBMS with extensibility
- **MySQL/MariaDB** — Popular open-source RDBMS for web applications
- **Oracle Database** — Enterprise RDBMS for mission-critical systems
- **Microsoft SQL Server** — Enterprise RDBMS for Windows ecosystems
- **SQLite** — Embedded database engine (most deployed in the world)
- **IBM Db2** — Enterprise RDBMS for large-scale systems
- **SAP HANA** — In-memory database for real-time analytics
- **Amazon Aurora** — Cloud-native MySQL/PostgreSQL compatible database
- **Google Cloud Spanner** — Globally distributed relational database
- **CockroachDB** — Distributed SQL database for global applications

## Data Warehousing
- **Snowflake** — Cloud-native data warehouse
- **Amazon Redshift** — Petabyte-scale data warehouse
- **Google BigQuery** — Serverless, highly scalable data warehouse
- **Microsoft Azure Synapse** — Analytics service and data warehouse
- **Teradata** — Enterprise data warehousing
- **Vertica** — Column-oriented analytics database
- **ClickHouse** — Column-oriented OLAP database
- **Apache Hive** — Data warehouse software on Hadoop
- **Presto/Trino** — Distributed SQL query engine for big data
- **Apache Druid** — Real-time analytics database

## NoSQL Databases (with SQL-like interfaces)
- **MongoDB** — Document database with aggregation pipeline
- **Couchbase** — Document database with N1QL (SQL-like query language)
- **Cassandra** — Wide-column store with CQL (Cassandra Query Language)
- **DynamoDB** — Key-value and document database with PartiQL
- **CockroachDB** — Distributed SQL with strong consistency
- **YugabyteDB** — Distributed SQL with PostgreSQL compatibility
- **TiDB** — Distributed SQL with MySQL compatibility
- **Vitess** — MySQL sharding and scaling
