# Go - Distinct Product Examples

## Cloud Infrastructure
- **Docker** — Containerization platform that revolutionized software deployment
- **Kubernetes** — Container orchestration system (Google's Borg successor)
- **Terraform** — Infrastructure as Code tool (HashiCorp)
- **Vault** — Secrets management and encryption (HashiCorp)
- **Consul** — Service mesh and service discovery (HashiCorp)
- **Nomad** — Workload orchestrator (HashiCorp)
- **etcd** — Distributed key-value store (Kubernetes' backbone)
- **CockroachDB** — Distributed SQL database
- **InfluxDB** — Time-series database
- **Vitess** — MySQL sharding and scaling (YouTube)

## Web Servers & APIs
- **Caddy** — Automatic HTTPS web server
- **Traefik** — Cloud-native reverse proxy and load balancer
- **Gin/Echo/Fiber** — High-performance web frameworks
- **Hugo** — Static site generator (one of the fastest)
- **Grafana** — Observability and monitoring platform
- **Prometheus** — Monitoring and alerting toolkit

## DevOps & CLI Tools
- **kubectl** — Kubernetes command-line tool
- **Helm** — Kubernetes package manager
- **gh** — GitHub CLI
- **Hugo CLI** — Static site generation
- **Delve** — Go debugger
- **golangci-lint** — Fast linter runner
- **Task** — Task runner (Make alternative)
- **Mage** — Make/Rake-like build tool

## Networking & Security
- **WireGuard** — Modern VPN protocol
- **CoreDNS** — DNS server (cloud-native)
- **Syncthing** — Continuous file synchronization
- **Caddy** — Web server with automatic TLS
- **Fission** — Serverless framework for Kubernetes
- **OpenTelemetry (Go SDK)** — Observability framework

## Databases & Storage
- **TiDB** — Distributed HTAP database
- **BadgerDB** — Fast embedded key-value store
- **Pebble** — RocksDB-inspired key-value store (CockroachDB)
- **MinIO** — S3-compatible object storage
- **SeaweedFS** — Distributed file system
- **NATS** — Cloud-native messaging system

## Microservices & Messaging
- **gRPC-Go** — High-performance RPC framework
- **NATS server** — Lightweight messaging
- **Watermill** — Event-driven library
- **Go-kit** — Microservices toolkit
- **Micro** — Microservices platform

## Developer Tools
- **GoLand** — JetBrains' Go IDE
- **gopls** — Official Go language server
- **Staticcheck** — Advanced static analysis
- **GoReleaser** — Automated release publishing
- **Air** — Live reload for Go development

## Blockchain & Crypto
- **Ethereum (Geth)** — Go implementation of Ethereum
- **Hyperledger Fabric** — Enterprise blockchain framework
- **Cosmos SDK** — Blockchain application framework
- **Tendermint** — Byzantine Fault Tolerant consensus

## Media & Streaming
- **Pion** — WebRTC implementation
- **LiveKit** — Real-time video/audio platform
- **Jitsi (parts)** — Video conferencing
