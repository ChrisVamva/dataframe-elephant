# C - Distinct Product Examples

## Operating Systems
- **Linux Kernel** — The most famous C product; ~30 million lines of C powering servers, desktops, Android, and embedded systems
- **Windows NT Kernel** — Core of modern Windows operating systems
- **FreeBSD/NetBSD/OpenBSD** — Unix-like operating systems
- **macOS XNU Kernel** — Hybrid kernel (Mach + BSD) at the heart of Apple's OS

## Embedded Systems & Firmware
- **Arduino Core** — Firmware for microcontrollers used by millions of hobbyists and professionals
- **ESP-IDF** — Espressif's IoT development framework for ESP32 chips
- **Zephyr RTOS** — Real-time operating system for resource-constrained devices
- **GRUB Bootloader** — Grand Unified Bootloader used by most Linux distributions

## Compilers & Interpreters
- **GCC** — GNU Compiler Collection, the reference C compiler
- **Clang/LLVM** — Modern C compiler infrastructure
- **CPython** — The reference Python interpreter, written in C
- **Ruby MRI** — Matz's Ruby Interpreter
- **PHP Zend Engine** — The core of PHP

## Databases
- **SQLite** — The most deployed database engine in the world (billions of copies)
- **PostgreSQL** — Advanced open-source relational database
- **MySQL/MariaDB** — Popular relational databases
- **Redis** — In-memory data structure store
- **MongoDB** — NoSQL document database

## Networking & Infrastructure
- **OpenSSL** — Cryptography library securing most of the internet
- **Nginx** — High-performance web server and reverse proxy
- **HAProxy** — Load balancer and proxy
- **libcurl** — Client-side URL transfer library
- **OpenSSH** — Secure shell implementation

## Graphics & Games
- **OpenGL Mesa** — Open-source graphics driver implementation
- **SDL** — Simple DirectMedia Layer for game development
- **Doom/Quake engines** — Classic game engines written in C
- **Blender (core)** — 3D creation suite core

## Scientific & Engineering
- **FFTW** — Fastest Fourier Transform in the West
- **GSL** — GNU Scientific Library
- **OpenCV (core)** — Computer vision library core
- **GNU Octave** — Numerical computation (MATLAB alternative)

## Utilities & Tools
- **Git** — Distributed version control system
- **Vim/Neovim** — Text editors
- **tmux** — Terminal multiplexer
- **coreutils** — GNU core utilities (ls, cp, mv, etc.)
- **zlib** — Compression library used everywhere
