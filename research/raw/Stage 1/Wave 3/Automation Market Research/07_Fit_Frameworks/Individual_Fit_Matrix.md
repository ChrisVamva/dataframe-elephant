# Individual fit matrix

| Individual profile | Best fit | Typical use cases | Learning curve |
|---|---|---|---|
| Non-technical knowledge worker | Zapier or Power Automate templates | Email, calendar, forms, notifications | Low |
| Operations generalist | Make or n8n Cloud | Multi-step workflows, data cleanup, approvals | Low–medium |
| Analyst / researcher | n8n, Make, Python plus APIs | Collection, enrichment, summaries, reports | Medium |
| Developer | Temporal, LangGraph, agent SDKs | Durable services, agents, tool orchestration | High |
| IT administrator | Power Automate, Workato, ServiceNow | Governance, identity, service operations | Medium–high |
| RPA specialist | UiPath or Power Automate Desktop | Desktop and legacy application automation | Medium–high |
| Founder / consultant | Zapier, Make, n8n | Client prototypes and internal leverage | Low–medium |

## Personal selection rule

Start with the smallest tool that can safely express the workflow. Move up the stack when you need branching complexity, code, durable recovery, governance, scale, or product-level differentiation.

## Individual risk

Personal automations often become invisible infrastructure. Document ownership, credentials, failure alerts, and what happens when the creator leaves or changes accounts.
