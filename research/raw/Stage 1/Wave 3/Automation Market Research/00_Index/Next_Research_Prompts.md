# Five additional automation-market research prompts

Use each prompt as a small, independent research task. Record official sources, access dates, vendor claims, and unresolved uncertainty.

## 1. Durable agents: LangGraph vs Temporal

Compare LangGraph and Temporal for a workflow that waits for human approval for 30 days, retries failed API calls, and must never duplicate a payment. Identify which runtime owns state, retries, timers, and compensation.

## 2. The real cost of an agent workflow

Calculate the monthly total cost of a 10,000-run agent workflow across model tokens, tool calls, orchestration, storage, tracing, human review, and failures. Compare one hosted platform with one self-hosted stack.

## 3. Agent interoperability in practice

Test whether MCP and A2A can be combined in one workflow without custom translation. Document discovery, authentication, task status, streaming, error handling, and the minimum adapter code required.

## 4. Automation platform failure patterns

Collect five public incidents or technical reports involving failed RPA, iPaaS, or AI-agent automations. Classify each failure as data quality, authentication, UI/API change, retry duplication, model error, governance, or ownership failure.

## 5. Which automation services fit small companies?

Create a decision guide for a 20-person company with limited engineering capacity, Microsoft 365, 500 monthly workflows, and sensitive customer data. Compare Power Automate, n8n, Make, Zapier, and a custom agent stack by cost, setup effort, governance, and maintenance.
