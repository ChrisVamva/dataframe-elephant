# Research Package Prompt: AI Safety Benchmark

Create a benchmark for home-AI intent interpretation and action safety.

Test normal requests, ambiguity, conflicting constraints, unknown devices, wrong-room references, multiple users, children, guests, adversarial speech, prompt injection, stale sensor data, network loss, and model uncertainty.

Score task success, unsafe action rate, unnecessary refusal, clarification quality, confirmation behavior, explainability, recovery, latency, and privacy exposure. Separate read-only, reversible, safety-critical, security-critical, and financial actions.

Deliver test cases, scoring rubric, results, failure examples, minimum guardrails, and a list of actions that must never be autonomous without explicit confirmation.
