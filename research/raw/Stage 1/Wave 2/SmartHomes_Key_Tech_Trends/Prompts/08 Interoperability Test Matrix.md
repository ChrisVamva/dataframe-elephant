# Research Package Prompt: Interoperability Test Matrix

Design and execute a repeatable test matrix for major smart-home ecosystems.

Test: onboarding, Matter multi-admin, Thread commissioning, device discovery, routines, permissions, firmware updates, local control, internet outage, border-router outage, cloud shutdown simulation, replacement, and migration.

Record ecosystem, device, firmware, controller, network topology, date, steps, expected result, observed result, recovery time, user effort, and evidence. Include at least one lock, sensor, light, camera, thermostat, and energy device where supported.

Deliver a comparison table, reproducible test protocol, failure taxonomy, and prioritized recommendations. Do not generalize from one device or vendor claim.
