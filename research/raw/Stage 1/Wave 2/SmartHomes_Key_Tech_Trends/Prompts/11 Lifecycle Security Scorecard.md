# Research Package Prompt: Lifecycle Security Scorecard

Build a scorecard for representative smart-home products across security and privacy lifecycle controls.

Assess identity, MFA, secure onboarding, encryption, network isolation, update delivery, support-period disclosure, vulnerability reporting, incident response, data retention, deletion/export, local control, end-of-life handling, and ownership transfer.

Use public documentation, product testing, certifications, regulatory filings, vulnerability databases, and support policies. Score evidence quality separately from control maturity.

Deliver the rubric, product comparison, missing-evidence list, consumer buying guidance, and engineering priorities. Penalize unsupported claims and note where compliance does not demonstrate practical safety.
