2. **Deterministic IDs:** SHA-256 based stable identifiers
3. **Read-Only DB Access:** Most operations use `read_only=True`
4. **Input Validation:** URL normalization and sanitization

2. **No Rate Limiting:** Archive operations could be resource-intensive
3. **Path Traversal:** Some functions accept user paths without validation

### 🔒 Recommendations
1. **Immediate:** Remove `.env` from git history
2. **Short-term:** Implement secret management (e.g., git-secret, SOPS)
3. **Long-term:** Add input validation for all file paths
