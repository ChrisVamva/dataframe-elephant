## 3. Detailed Changes by Subsystem

### 3.1 Prompt Architecture & Disambiguation (Phases 0–2)

#### Phase 0: Gate Identity Disambiguation
Fixed critical naming collisions where prompts previously conflated evaluation gates from `Protocols/Research-Evaluation.md` with acceptance gates from `Protocols/FollowUpResearch.md`:
- Standardized prefix qualification across all templates and partials:
  - `RE:Gate A` through `RE:Gate F`: Research evaluation gates (Scope, Source Quality, Claim Alignment, Method, Counterevidence, Data Readiness).
  - `FU:Gate A` through `FU:Gate D`: Follow-up research acceptance gates (Scope Anchor, Falsifier Check, Provenance Density, Dossier Completeness).
  - `WB:1` / `WB:2`: Write-back checklist items (Stage 2 patch, agenda status update).
- Corrected `NextResearchPrompt.md` (which previously claimed "Gate E falsification", an invented gate).

#### Phase 1: Modular Partial Extraction
- Extracted duplicated sections out of raw markdown prompts into `prompts/lib/`.
- Moved `The components to investigate.md` out of the operational prompt deck into `prompts/lib/lens_reference.md`.
- Converted all items in `Rules and Regulations/Commander Deck/prompts/` into thin forwarders pointing to `prompts/templates/`.

#### Phase 2: Assembly Tooling & Tier 1 Automated Lint
- **`src/prompt_core.py`**:
  - Implements stdlib-only template composition (`resolve_includes`, `render`, `parse_frontmatter`). Supports `<!-- include: lib/... -->` directives and `{{var}}` substitutions.
  - Implements Tier 1 automated static lint checks:
    - `check_includes` (R1): Ensures every include target exists within `prompts/` and detects dependency cycles.
    - `check_bare_gates` (R2): Prohibits unqualified gate references (e.g. bare "Gate A") in active templates and partials.
    - `check_template_purity` (R3): Guarantees evidence rules and claim taxonomy live strictly in their canonical library partials.
    - `check_paths` (R4): Verifies that all frontmatter inputs, partials, and backticked repo paths actually exist on disk.
    - `check_commands` (R5): Verifies that any executable command cited in a prompt matches `AGENTS.md` verbatim.
- **`scripts/assemble_prompt.py`**: Thin CLI entry point for assembling prompt dispatches with context injection (`--template`, `--var`, `--context`, `--out`).
- **`src/tests/test_prompts.py`**: 18 unit and property tests verifying prompt rendering, cycle detection, heuristic path checkers, and lint validation (including negative control mutations).
