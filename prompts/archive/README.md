# `prompts/archive/` — superseded prompt versions

When a template or partial is superseded (its `status:` becomes `superseded`),
the previous full text is moved here as
`<name>_v<version>_<YYYY-MM-DD>.md` instead of being deleted — the same
no-silent-overwrite principle as `Rules and Regulations/Protocols/Research-Evaluation.md` §9.

Nothing is read from this directory at dispatch time. It exists so a reviewer
can answer "what did the prompt say when this dossier was produced?"
