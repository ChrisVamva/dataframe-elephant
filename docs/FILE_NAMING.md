# File Naming Convention (L5)
- Source modules: `snake_case.py`, descriptive (e.g., `viz_core.py`, `stage2_import_core.py`).
- Scripts: `snake_case.py`, CLI entry points (e.g., `build_visualization_notebooks.py`).
- Schemas: `<domain>.sql` (e.g., `stage2.sql`, `citations.sql`).
- Notebooks: `<wave>_<name>.ipynb` (e.g., `01_pricing_and_architecture.ipynb`).
- No mixed `camelCase` vs `snake_case` in new files.
